# 英文學習遊戲 - 規格說明

## 專案概述
- **專案名稱**: English Learning Game
- **類型**: 網頁版單人遊戲
- **核心功能**: 結合聽、讀、寫三種學習模式的英文單字遊戲
- **目標用戶**: 英語學習者

## UI/UX 規格

### 布局結構
- 頂部：遊戲標題 + 進度指示器
- 中部：遊戲主區域（根據模式切換）
- 底部：導航按鈕 + 統計資訊

### 視覺設計
- **色彩方案**:
  - 主色：#4F46E5 (靛藍)
  - 成功：#10B981 (綠)
  - 錯誤：#EF4444 (紅)
  - 背景：#F3F4F6 (淺灰)
  - 卡片背景：#FFFFFF
- **字體**: "Nunito", sans-serif
- **間距**: 16px 基礎單位
- **效果**: 圓角 12px，輕微陰影

### 遊戲模式

#### 1. 聽力模式 (Listen)
- 顯示喇叭圖標 + 播放按鈕
- 點擊播放英文發音
- 選擇正確的中文翻譯（4選1）
- 答對：綠色動畫 + 下一題
- 答錯：紅色閃爍 + 顯示正確答案

#### 2. 閱讀模式 (Read)
- 顯示英文句子/單字
- 4選1 選擇正確翻譯
- 即時反饋

#### 3. 寫作模式 (Write)
- 顯示中文意思
- 輸入框填入正確英文
- 支援大小寫寬容
- 錯誤時顯示正確答案與提示

### 遊戲流程
1. 選擇模式（聽/讀/寫）
2. 系統隨機出題
3. 用戶作答
4. 即時評分 + 錯誤糾正
5. 累積積分，顯示統計

## 單字庫
包含 20 個基礎英文單字，分為：
- 動物：dog, cat, bird, fish
- 食物：apple, banana, rice, bread
- 顏色：red, blue, green, yellow
- 數字：one, two, three, four, five
- 動作：run, eat, sleep, drink
